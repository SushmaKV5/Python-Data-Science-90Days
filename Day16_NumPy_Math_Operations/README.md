# Day 16 – NumPy Math Operations (Python with Data Science)

## Task Overview
This task focuses on performing mathematical and statistical operations using NumPy. It demonstrates how NumPy enables fast, vectorized computations on arrays, which is essential for data analysis and machine learning workflows.

## Objective
- Perform element-wise mathematical operations  
- Apply scalar operations on arrays  
- Use aggregate functions (sum, mean, max, min)  
- Perform matrix-based computations  
- Explore power and trigonometric functions  

## Technologies Used
- Python  
- NumPy  

## Key Implementations
- Element-wise addition, subtraction, multiplication, and division  
- Scalar operations on NumPy arrays

- Row-wise and column-wise operations using `axis`  
- Square, square root, sine, and cosine functions  
- Basic matrix computations  

## Concepts Covered
