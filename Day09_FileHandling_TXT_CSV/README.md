# Day 09 – File Handling (TXT & CSV)

## Objective
Learn how to read and write text and CSV files in Python
using built-in file handling methods and the csv module.

## Tools Used
- Python 3
- csv module

## Tasks Completed
- Read content from a text file
- Wrote data into a new text file
- Read data from a CSV file
- Created and wrote data into a CSV file

## Key Learnings
- open() function is used for file operations
- Files must be closed after operations
- CSV module helps process tabular datasets
- File handling is essential for real-world data processing
