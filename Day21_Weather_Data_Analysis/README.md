# Day 21 – Weather Data Analysis using NumPy (Python with Data Science)

## Task Overview
This mini project focuses on analyzing weather temperature data using NumPy. It demonstrates how numerical datasets can be processed efficiently to extract meaningful insights such as average temperature, maximum and minimum values, and temperature variation.

## Objective
- Load temperature data from a file  
- Analyze daily weather data using NumPy  
- Calculate statistical measures like mean, max, and min  
- Identify temperatures above the average  
- Sort and analyze temperature values  

## Technologies Used
- Python  
- NumPy  

## Key Implementations
- Loading dataset using `np.loadtxt()`  
- Mean temperature calculation using `np.mean()`  
- Maximum and minimum temperature using `np.max()` and `np.min()`  
- Temperature variation using `np.std()`  
- Filtering temperatures above average  
- Sorting data using `np.sort()`  

## Concepts Covered
- Numerical Data Analysis  
- Descriptive Statistics  
- Dataset Loading  
- Array Filtering  
- Data Sorting  

## Learning Outcome
By completing this task, I learned how to analyze real-world numerical datasets using NumPy. This helps in extracting insights from raw data and forms the foundation for more advanced data analysis and machine learning workflows.
