# Day 35 – Subplots & Styling (Python with Data Science)

## Task Overview
This task focuses on creating multiple visualizations within a single figure using subplots. It demonstrates how to organize different chart types into a structured dashboard for better data analysis and presentation.

## Objective
- Create multiple plots using subplots  
- Combine different visualization types  
- Build dashboard-style visualizations  
- Improve chart readability and structure  

## Technologies Used
- Python  
- Matplotlib  
- NumPy  

## Key Implementations
- Creating subplots using `plt.subplot()`  
- Displaying multiple charts in one figure  
- Combining line, bar, histogram, and scatter plots  
- Adding titles, labels, and overall figure title  
- Adjusting layout using `plt.tight_layout()`  

## Concepts Covered
- Subplots  
- Multi-chart Visualization  
- Dashboard Design  
- Data Representation  
- Visualization Structure  

## Learning Outcome
By completing this task, I learned how to organize multiple visualizations into a single dashboard. This improves the clarity of data presentation and helps in analyzing multiple aspects of a dataset effectively.
