# Day 18 – Random Data Generation using NumPy (Python with Data Science)

## Task Overview
This task focuses on generating random data using NumPy. It demonstrates how NumPy provides powerful tools for creating random integers, floats, matrices, and normally distributed data, which are widely used in data analysis, simulations, and machine learning.

## Objective
- Generate random integers and floats  
- Create random 1D and 2D arrays  
- Work with normal distribution  
- Randomly select and shuffle values  
- Set random seed for reproducibility  

## Technologies Used
- Python  
- NumPy  

## Key Implementations
- Random integer generation using `np.random.randint()`  
- Random float generation using `np.random.rand()`  
- Normal distribution values using `np.random.randn()`  
- Random selection using `np.random.choice()`  
- Shuffling arrays using `np.random.shuffle()`  
- Reproducible results using `np.random.seed()`  

## Concepts Covered
- Random Number Generation  
- Probability Distribution (Normal Distribution)  
- Data Simulation  
- Reproducibility in Experiments  
- Array Manipulation  

## Learning Outcome
By completing this task, I gained practical experience in generating and analyzing random data using NumPy. This is an essential skill for simulations, statistical analysis, machine learning model training, and creating synthetic datasets for testing and experimentation.
