# Day 36 – Seaborn Basics (Python with Data Science)

## Task Overview
This task introduces Seaborn, a powerful data visualization library built on top of Matplotlib. It provides high-level functions for creating attractive and informative statistical graphics.

## Objective
- Create professional visualizations using Seaborn  
- Analyze relationships between variables  
- Visualize distributions and categorical data  
- Improve visual clarity and presentation  

## Technologies Used
- Python  
- Seaborn  
- Matplotlib  
- Pandas  

## Key Implementations
- Loading dataset using `sns.load_dataset()`  
- Creating scatter plots using `sns.scatterplot()`  
- Visualizing distributions using `sns.histplot()`  
- Detecting outliers using `sns.boxplot()`  
- Comparing categories using `sns.barplot()`  

## Concepts Covered
- Data Visualization  
- Statistical Plots  
- Distribution Analysis  
- Categorical Analysis  
- Data Relationships  

## Learning Outcome
By completing this task, I gained hands-on experience in creating clean and professional visualizations using Seaborn. This helps in better understanding data patterns and presenting insights effectively in data science projects.
