# Day 23 – Reading CSV/Excel Files (Python with Data Science)

## Task Overview
This task focuses on reading external datasets using Pandas. Data scientists commonly work with datasets stored in CSV or Excel files, and Pandas provides powerful tools to load, inspect, and analyze these datasets efficiently.

## Objective
- Read CSV files using Pandas  
- Understand dataset structure  
- View dataset rows and columns  
- Generate statistical summaries  
- Access specific columns of a dataset  

## Technologies Used
- Python  
- Pandas  
- Openpyxl  

## Key Implementations
- Loading CSV files using `pd.read_csv()`  
- Viewing dataset rows using `.head()` and `.tail()`  
- Inspecting dataset information using `.info()`  
- Generating statistical summaries using `.describe()`  
- Accessing dataset columns using indexing  

## Concepts Covered
- Dataset Loading  
- Data Inspection  
- DataFrame Structure  
- Column Selection  
- Descriptive Statistics  

## Learning Outcome
By completing this task, I learned how to load and inspect real-world datasets using Pandas. This is a fundamental skill in data analysis, as most data science projects begin with reading and exploring datasets before performing cleaning and analysis.
