# Day 39 – Variance & Standard Deviation (Python with Data Science)

## Task Overview
This task focuses on understanding statistical measures of data dispersion, specifically variance and standard deviation. These metrics help in analyzing how data values are spread around the mean.

## Objective
- Calculate variance and standard deviation  
- Understand data spread and dispersion  
- Apply statistical functions using NumPy and Pandas  

## Technologies Used
- Python  
- NumPy  
- Pandas  

## Key Implementations
- Variance calculation using `np.var()`  
- Standard deviation calculation using `np.std()`  
- Using Pandas functions `var()` and `std()`  
- Comparing NumPy and Pandas results  

## Concepts Covered
- Variance  
- Standard Deviation  
- Data Dispersion  
- Statistical Analysis  

## Learning Outcome
By completing this task, I gained a deeper understanding of how data is distributed around the mean. Variance and standard deviation are essential for identifying data variability and are widely used in data analysis and machine learning.
