# Day 10 – Exception Handling (Safe Calculator)

## Objective
Learn how to handle runtime errors in Python using try, except,
else, and finally blocks by building a safe calculator application.

## Tools Used
- Python 3
- VScode

## Tasks Completed
- Implemented basic exception handling
- Handled ZeroDivisionError
- Handled ValueError for invalid input
- Built a safe calculator with error handling

## Key Learnings
- try-except prevents program crashes
- Multiple except blocks handle specific errors
- finally block executes regardless of errors
- Exception handling improves program reliability
