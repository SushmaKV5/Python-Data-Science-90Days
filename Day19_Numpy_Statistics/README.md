# Day 19 – NumPy Statistics (Python with Data Science)

## Task Overview
This task focuses on performing statistical analysis using NumPy. It demonstrates how NumPy provides efficient functions to compute statistical measures such as mean, median, standard deviation, variance, and percentiles, which are essential for understanding and analyzing datasets.

## Objective
- Calculate mean and median of data  
- Compute standard deviation and variance  
- Find minimum and maximum values  
- Calculate percentiles for data distribution  
- Perform statistical operations on 1D and 2D arrays  

## Technologies Used
- Python  
- NumPy  

## Key Implementations
- Mean calculation using `np.mean()`  
- Median calculation using `np.median()`  
- Standard deviation using `np.std()`  
- Variance calculation using `np.var()`  
- Minimum and maximum values using `np.min()` and `np.max()`  
- Percentile calculations using `np.percentile()`  
- Row-wise and column-wise statistics using the `axis` parameter  

## Concepts Covered
- Descriptive Statistics  
- Data Distribution  
- Statistical Measures  
- Axis-based Computation  
- Numerical Data Analysis  

## Learning Outcome
By completing this task, I gained practical experience in performing statistical analysis using NumPy. These techniques help in understanding data distribution and summarizing datasets, which are fundamental steps in data analysis and machine learning workflows.
