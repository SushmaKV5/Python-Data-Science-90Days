# Day 06 – Lists & Tuples (Student Marks Analysis)

## Objective
Understand how to use lists and tuples in Python and apply them
to analyze student marks using basic data analysis techniques.

## Tools Used
- Python 3
- VScode

## Tasks Completed
- Practiced list creation, indexing, and modification
- Learned the difference between lists and tuples
- Collected student marks using lists
- Calculated total, average, highest, and lowest marks
- Assigned grades based on average marks

## Key Learnings
- Lists are mutable, tuples are immutable
- Built-in functions simplify data analysis
- Lists are useful for storing dynamic data
- Simple logic can turn raw data into insights
