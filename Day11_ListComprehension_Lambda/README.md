# Day 11 – List Comprehension & Lambda Functions

## Objective
Learn concise data processing techniques using list comprehension
and lambda functions for faster and cleaner Python code.

## Tools Used
- Python 3

## Tasks Completed
- Generated lists using list comprehension
- Applied conditional filtering in lists
- Created lambda functions for small operations
- Used map() and filter() with lambda

## Key Learnings
- List comprehension reduces multiple lines of code
- Lambda functions are useful for short operations
- map() applies functions to all elements
- filter() selects elements based on conditions
