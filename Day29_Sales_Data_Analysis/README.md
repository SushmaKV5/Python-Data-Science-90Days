# Day 29 – Sales Data Analysis (Python with Data Science)

## Task Overview
This mini project focuses on analyzing sales data using Pandas and visualizing insights using Matplotlib. It demonstrates how data can be processed and transformed into meaningful visual insights for better decision-making.

## Objective
- Analyze sales and profit data  
- Group data by categories  
- Identify top-performing products  
- Visualize insights using charts  
- Understand real-world data analysis workflow  

## Technologies Used
- Python  
- Pandas  
- Matplotlib  

## Key Implementations
- Loading dataset using `pd.read_csv()`  
- Aggregating sales and profit using `groupby()`  
- Identifying top-selling product using `idxmax()`  
- Visualizing data using bar charts  
- Creating multiple visual insights  

## Concepts Covered
- Data Analysis  
- Data Aggregation  
- Data Visualization  
- Business Insights  
- Real-world Dataset Handling  

## Learning Outcome
By completing this task, I gained hands-on experience in analyzing real-world sales data and visualizing insights using Python. This project helps in understanding how data-driven decisions are made using analysis and visualization techniques.
