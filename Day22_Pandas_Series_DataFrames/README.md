# Day 22 – Pandas Series & DataFrames (Python with Data Science)

## Task Overview
This task introduces the fundamentals of Pandas, a powerful library used for data manipulation and analysis in Python. It demonstrates how to create and work with Pandas Series and DataFrames, which are essential structures for handling tabular datasets in data science.

## Objective
- Create and manipulate Pandas Series  
- Create and explore DataFrames  
- Access rows and columns of a dataset  
- Understand dataset structure and summary statistics  
- Perform basic data inspection

## Technologies Used
- Python  
- Pandas  
- NumPy  

## Key Implementations
- Creating a Pandas Series using `pd.Series()`  
- Creating labeled Series with custom indices  
- Building a DataFrame from a dictionary using `pd.DataFrame()`  
- Accessing columns and rows using indexing  
- Viewing dataset structure using `.shape` and `.columns`  
- Generating statistical summaries using `.describe()`

## Concepts Covered
- Pandas Series  
- DataFrame Structure  
- Data Selection and Indexing  
- Dataset Inspection  
- Descriptive Statistics  

## Learning Outcome
By completing this task, I gained hands-on experience with Pandas Series and DataFrames, which are the core data structures used in data analysis. This task strengthens my ability to organize, inspect, and manipulate tabular datasets, forming a strong foundation for real-world data science workflows.
