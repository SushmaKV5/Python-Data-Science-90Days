# Day 34 – Scatter Plots (Python with Data Science)

## Task Overview
This task focuses on visualizing relationships between variables using scatter plots. Scatter plots are widely used in data analysis to identify patterns, trends, and correlations between two variables.

## Objective
- Create scatter plots to analyze relationships  
- Compare multiple datasets using scatter plots  
- Understand correlation patterns  
- Visualize trends in data  

## Technologies Used
- Python  
- Matplotlib  
- NumPy  

## Key Implementations
- Creating scatter plots using `plt.scatter()`  
- Visualizing relationship between study hours and scores  
- Comparing multiple datasets in a single plot  
- Adding labels and legends for clarity  

## Concepts Covered
- Scatter Plots  
- Correlation Analysis  
- Trend Visualization  
- Comparative Analysis  
- Data Relationships  

## Learning Outcome
By completing this task, I gained practical experience in visualizing relationships between variables using scatter plots. This is essential for identifying correlations and patterns in datasets, which is a key step in data analysis and machine learning workflows.
