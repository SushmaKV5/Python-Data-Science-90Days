# Day 05 – Functions (Calculator Using Functions)

## Objective
Learn how to create reusable blocks of code using functions
and implement a simple calculator using function-based logic.

## Tools Used
- Python 3
- VScode

## Tasks Completed
- Created functions with and without parameters
- Used return values in functions
- Built a calculator using multiple functions
- Implemented error handling for division

## Key Learnings
- Functions improve code reusability
- Parameters allow flexible inputs
- Return statements send output back to caller
- Breaking programs into functions improves readability

- basic_functions.py
- calculator_functions.py
