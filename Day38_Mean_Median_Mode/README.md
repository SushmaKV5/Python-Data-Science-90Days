# Day 38 – Mean, Median, Mode (Python with Data Science)

## Task Overview
This task focuses on understanding basic statistical measures such as mean, median, and mode. These measures are essential for summarizing and analyzing numerical data in data science.

## Objective
- Calculate mean, median, and mode  
- Understand differences between statistical measures  
- Apply statistical functions using NumPy and Pandas  

## Technologies Used
- Python  
- NumPy  
- Pandas  

## Key Implementations
- Mean calculation using `np.mean()`  
- Median calculation using `np.median()`  
- Mode calculation using `pd.Series().mode()`  
- Data conversion into NumPy arrays and Pandas Series  

## Concepts Covered
- Descriptive Statistics  
- Central Tendency  
- Data Analysis Basics  

## Learning Outcome
By completing this task, I gained a strong understanding of fundamental statistical concepts such as mean, median, and mode. These are essential for analyzing datasets and form the foundation for advanced data science techniques.
