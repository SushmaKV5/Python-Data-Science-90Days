# Day 32 – Line & Bar Charts (Python with Data Science)

## Task Overview
This task focuses on creating and improving line and bar charts using Matplotlib. It demonstrates how to compare datasets and present information visually using clear and structured charts.

## Objective
- Create line charts for comparison  
- Build grouped bar charts  
- Visualize data using horizontal bar charts  
- Improve chart readability with labels and legends  

## Technologies Used
- Python  
- Matplotlib  

## Key Implementations
- Line chart comparison using `plt.plot()`  
- Grouped bar chart using `plt.bar()`  
- Horizontal bar chart using `plt.barh()`  
- Adding markers, grid, and legends  
- Customizing axes and ticks  

## Concepts Covered
- Data Visualization  
- Comparative Analysis  
- Chart Customization  
- Visual Clarity  
- Data Representation  

## Learning Outcome
By completing this task, I improved my ability to create clear and comparative visualizations using Matplotlib. These skills are important for presenting data insights effectively in data science and analytics projects.
