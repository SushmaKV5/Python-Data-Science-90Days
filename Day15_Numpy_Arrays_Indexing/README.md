# Day 15 – NumPy Arrays & Indexing (Python with Data Science)

## Task Overview
This task focuses on learning the fundamentals of NumPy arrays, including array creation, indexing, slicing, reshaping, and basic operations. NumPy is a core library in Data Science that enables efficient numerical computations and handling of multi-dimensional data.

## Objective
- Understand NumPy arrays  
- Perform indexing and slicing  
- Access rows and columns in 2D arrays  
- Learn array shape, dimension, and reshaping  
- Apply basic vectorized operations  

## Technologies Used
- Python  
- NumPy Library  

## Key Implementations
- Creation of 1D and 2D NumPy arrays  
- Indexing elements using positions  
- Slicing arrays using range indexing  
- Accessing specific rows and columns  
- Performing arithmetic operations on arrays  
- Reshaping arrays for structured data handling  


## Concepts Covered
- NumPy Array vs Python List  
- Indexing and Slicing  
- Array Shape and Dimensions  
- Vectorized Operations  
- Reshaping Arrays

By completing this task, I gained hands-on experience with NumPy arrays, indexing, slicing, and vectorized operations, which are essential for data analysis and machine learning workflows. This task strengthens my foundation in numerical computing for Data Science.
