# Day 13 – Modules & Packages Usage (Python Task)

## Task Overview
This task focuses on understanding how to use modules and packages in Python to write clean, reusable, and organized code. Instead of writing everything in one file, the program is divided into multiple files (modules) and imported where needed.

## Objective
- Learn what modules and packages are  
- Create and import custom modules  
- Use built-in modules  
- Improve code structure and reusability  

## Features Implemented
- Created a custom module with functions  
- Imported functions into the main file  
- Used modular programming approach  
- Demonstrated code reusability and clean structure  


## Description of Files
- **main.py** – Main program that imports and uses functions from the module  
- **math_operations.py** – Custom module containing reusable functions  
- **README.md** – Project documentation  

## How to Run
1. Open the project folder in your code editor  
2. Run the following command in terminal:
    python main.py


## Concepts Covered
- Modules in Python  
- Import statements (`import`, `from module import`)  
- Code modularization  
- Function reuse  
- Clean project structure  

## Learning Outcome
Through this task, I learned how to create and use custom modules, import functions, and organize Python code efficiently. This improves readability, scalability, and maintainability of programs, which is an essential skill for real-world Python and Data Science projects.
