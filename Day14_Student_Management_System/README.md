# Day 14 – Student Management System (Python Mini Project)

## Project Overview
This project is a simple menu-driven Student Management System built using Python. It allows users to add, view, search, and delete student records using lists and dictionaries. The goal of this project is to practice core Python fundamentals through a real-world mini application.

## Features
- Add new student details
- View all student records
- Search for a student by name
- Delete a student record
- Menu-driven user interface

## Technologies Used
- Python (Core)
- Lists & Dictionaries
- Functions & Modules
- Loops & Conditional Statements


## How to Run the Project
1. Clone the repository or download the folder  
2. Open the project in your code editor  
3. Run the following command in terminal:
    python main.py


## Concepts Covered
- Data Structures (List & Dictionary)
- Modular Programming
- User Input Handling
- Function Design
- Basic CRUD Operations in Python

## Learning Outcome
By completing this project, I learned how to structure a Python program using modules, manage data using dictionaries, and build a real-world command-line application with clean and reusable code as part of my 90 Days Python with Data Science roadmap.
