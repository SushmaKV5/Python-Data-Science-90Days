# Day 31 – Matplotlib Basics (Python with Data Science)

## Task Overview
This task introduces the basics of data visualization using Matplotlib. It demonstrates how to create simple plots such as line charts and bar charts to represent data visually, which is an essential skill in data analysis.

## Objective
- Create line plots and bar charts  
- Add titles and labels to plots  
- Visualize multiple datasets  
- Understand basic plotting techniques  

## Technologies Used
- Python  
- Matplotlib  

## Key Implementations
- Line plot using `plt.plot()`  
- Bar chart using `plt.bar()`  
- Adding titles and axis labels  
- Plotting multiple datasets on the same graph  
- Using legends to differentiate data  

## Concepts Covered
- Data Visualization  
- Line Charts  
- Bar Charts  
- Plot Customization  
- Visual Data Representation  

## Learning Outcome
By completing this task, I gained hands-on experience in visualizing data using Matplotlib. This helps in understanding patterns and trends in data, which is crucial for effective data analysis and communication of insights.
