# Day 37 – COVID Data Visualization (Python with Data Science)

## Task Overview
This mini project focuses on analyzing and visualizing COVID-19 data using Pandas and Seaborn. It demonstrates how real-world datasets can be explored and transformed into meaningful visual insights.

## Objective
- Analyze COVID-19 dataset  
- Compare cases across countries  
- Visualize relationships between variables  
- Identify patterns using charts  

## Technologies Used
- Python  
- Pandas  
- Seaborn  
- Matplotlib  

## Key Implementations
- Loading dataset using `pd.read_csv()`  
- Creating bar charts for confirmed cases and deaths  
- Visualizing relationships using scatter plots  
- Generating correlation heatmap using `sns.heatmap()`  

## Concepts Covered
- Data Visualization  
- Correlation Analysis  
- Categorical Comparison  
- Real-world Dataset Analysis  

## Learning Outcome
By completing this task, I gained hands-on experience in analyzing real-world data and visualizing insights using Seaborn. This project strengthens my ability to interpret data and present meaningful findings effectively.
