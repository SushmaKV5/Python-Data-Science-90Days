# Day 24 – Data Selection & Filtering (Python with Data Science)

## Task Overview
This task focuses on selecting and filtering data from datasets using Pandas. Data selection and filtering are essential techniques used in data analysis to extract meaningful subsets of data based on specific conditions.

## Objective
- Select columns from a dataset  
- Filter rows based on conditions  
- Apply multiple filtering conditions  
- Sort data based on column values  
- Analyze subsets of a dataset  

## Technologies Used
- Python  
- Pandas  

## Key Implementations
- Selecting single and multiple columns using indexing  
- Filtering rows using conditional expressions  
- Applying multiple filtering conditions using logical operators  
- Sorting datasets using `sort_values()`  
- Extracting subsets of data for analysis  

## Concepts Covered
- Data Selection  
- Data Filtering  
- Conditional Queries  
- Sorting Data  
- Dataset Subsetting  

## Learning Outcome
By completing this task, I gained hands-on experience in selecting and filtering datasets using Pandas. These techniques are fundamental for exploring datasets, identifying patterns, and preparing data for further analysis and machine learning workflows.
