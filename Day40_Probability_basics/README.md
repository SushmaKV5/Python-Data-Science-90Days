# Day 40 – Probability Basics (Python with Data Science)

## Task Overview
This task introduces the fundamental concepts of probability, which are essential in data science and machine learning. It demonstrates how probability can be understood through simulations and basic calculations.

## Objective
- Understand basic probability concepts  
- Simulate random experiments  
- Calculate probabilities using code  
- Compare theoretical and experimental probability  

## Technologies Used
- Python  
- NumPy  

## Key Implementations
- Coin toss simulation using `np.random.choice()`  
- Dice roll simulation using `np.random.randint()`  
- Probability calculation using frequency approach  
- Manual probability calculation using formula  

## Concepts Covered
- Probability Basics  
- Random Experiments  
- Theoretical Probability  
- Experimental Probability  

## Learning Outcome
By completing this task, I gained a foundational understanding of probability and how it applies to data science. This knowledge is crucial for machine learning algorithms, statistical analysis, and decision-making processes.
