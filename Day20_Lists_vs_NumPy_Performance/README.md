# Day 20 – Performance Comparison (Python List vs NumPy)

## Task Overview
This task focuses on comparing the performance of Python lists and NumPy arrays when performing numerical computations. It demonstrates how NumPy uses vectorized operations to process large datasets efficiently, making it significantly faster than traditional Python loops.

## Objective
- Compare computation speed of Python lists and NumPy arrays  
- Understand vectorized operations in NumPy  
- Measure execution time using Python's time module  
- Perform addition on large datasets  

## Technologies Used
- Python  
- NumPy  

## Key Implementations
- Created large datasets using Python lists and NumPy arrays  
- Performed element-wise addition using loops for lists  
- Performed vectorized addition using NumPy arrays  
- Measured execution time using the `time` module  
- Compared computation speed between both approaches  

## Concepts Covered
- Performance Optimization  
- Vectorized Computation  
- Execution Time Measurement  
- Efficient Numerical Processing  
- Large Dataset Handling  

## Learning Outcome
By completing this task, I learned how NumPy significantly improves computational efficiency through vectorized operations. This highlights why NumPy is widely used in data science and machine learning for handling large-scale numerical data.
