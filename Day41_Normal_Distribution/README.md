# Day 41 – Normal Distribution (Python with Data Science)

## Task Overview
This task focuses on understanding and visualizing the normal distribution, also known as the Gaussian distribution. It is one of the most important concepts in statistics and is widely used in data science and machine learning.

## Objective
- Generate normally distributed data  
- Visualize distribution using histograms  
- Understand the impact of mean and standard deviation  
- Compare multiple distributions  

## Technologies Used
- Python  
- NumPy  
- Matplotlib  

## Key Implementations
- Generating data using `np.random.normal()`  
- Plotting histograms using `plt.hist()`  
- Comparing distributions with different parameters  
- Visualizing spread and central tendency  

## Concepts Covered
- Normal Distribution  
- Mean and Standard Deviation  
- Data Distribution  
- Statistical Visualization  

## Learning Outcome
By completing this task, I gained a strong understanding of the normal distribution and how it behaves. This concept is fundamental in data science, as many real-world datasets follow a normal distribution, and it plays a key role in statistical analysis and machine learning models.
