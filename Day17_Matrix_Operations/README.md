# Day 17 – Matrix Operations using NumPy (Python with Data Science)

## Task Overview
This task focuses on performing matrix operations using NumPy. Matrix computations are fundamental in Linear Algebra and form the backbone of many Data Science and Machine Learning algorithms.

## Objective
- Create matrices using NumPy  
- Perform matrix addition and subtraction  
- Understand element-wise vs matrix multiplication  
- Compute transpose of a matrix  
- Calculate determinant and inverse  
- Determine matrix rank and identity matrix  

## Technologies Used
- Python  
- NumPy  

## Key Implementations
- Matrix creation using `np.array()`  
- Matrix addition and subtraction  
- Element-wise multiplication using `*`  
- Matrix multiplication using `np.dot()`  
- Transpose using `.T`  
- Determinant using `np.linalg.det()`  
- Inverse using `np.linalg.inv()`  
- Identity matrix using `np.eye()`  
- Matrix rank using `np.linalg.matrix_rank()`  

## Concepts Covered
- Linear Algebra Fundamentals  
- Matrix Arithmetic  
- Determinant and Inverse  
- Identity Matrix  
- Matrix Rank  
- Vectorized Computation  

## Learning Outcome
By completing this task, I strengthened my understanding of matrix operations and core linear algebra concepts using NumPy. These skills are essential for advanced topics in Machine Learning, Deep Learning, and data transformation workflows.
