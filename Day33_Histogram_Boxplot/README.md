# Day 33 – Histograms & Boxplots (Python with Data Science)

## Task Overview
This task focuses on visualizing data distribution using histograms and boxplots. These plots help in understanding how data is spread, identifying outliers, and analyzing statistical properties of datasets.

## Objective
- Create histograms to visualize data distribution  
- Use boxplots to detect outliers and spread  
- Compare multiple datasets visually  
- Understand distribution patterns  

## Technologies Used
- Python  
- Matplotlib  
- NumPy  

## Key Implementations
- Histogram creation using `plt.hist()`  
- Boxplot visualization using `plt.boxplot()`  
- Comparing multiple datasets using boxplots  
- Generating sample datasets using NumPy  

## Concepts Covered
- Data Distribution  
- Outlier Detection  
- Quartiles and Median  
- Comparative Analysis  
- Statistical Visualization  

## Learning Outcome
By completing this task, I gained hands-on experience in analyzing data distribution using histograms and boxplots. These techniques are essential for identifying patterns, detecting anomalies, and understanding the underlying structure of datasets in data analysis and machine learning.
