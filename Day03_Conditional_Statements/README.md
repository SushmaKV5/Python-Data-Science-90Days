# Day 03 – Conditional Statements (if–else)

## Objective
Learn decision-making in Python using if, elif, and else
statements through simple real-world programs.

## Tools Used
- Python 3
- VScode

## Tasks Completed
- Checked whether a number is odd or even
- Built a grade calculator using conditional logic
- Used comparison operators for decision making

## Key Learnings
- if–else controls program flow
- elif is used for multiple conditions
- Conditions must be logically ordered

## Files
- odd_even.py
- grade_calculator.py
